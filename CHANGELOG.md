# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-04-21

### Added
- Initial release of Agent Orchestrator Dashboard
- Agent discovery from OpenClaw skills directory
- Real-time agent status monitoring
- GitHub integration (PRs and issues)
- Cost tracking and metrics
- Modern UI with shadcn/ui design system
- Docker support with docker-compose
- WebSocket for real-time updates

### Features
- Dashboard with agent overview
- Agent management page with run/config capabilities
- Workflow visualization
- Metrics and cost analysis
- Responsive sidebar navigation
- Dark mode UI (black/gray with #ffbe00 accents)

### Technical
- FastAPI backend with async support
- React frontend with Tailwind CSS
- PostgreSQL for data persistence
- Redis for caching
- Docker containerization
